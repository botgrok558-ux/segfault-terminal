// how it works

No API key. No magic. Just real data and a mean streak.

>_

/roast <repo>

3 calls to the public GitHub REST API: repo metadata, languages and the file tree. Signals like missing tests, no CI, no license, committed node_modules or .env, huge files and the last push date feed a deterministic Crash Score.

!!

/debug

Paste a stack trace. A rule engine recognises 30+ classic failures (segfault, NullPointerException, undefined, KeyError, CORS, ECONNREFUSED, OOM, Rust borrow errors...), finds the crash site and suggests a fix.
